# Design & UI Preferences

- Prefers the Lucide icon pack for web UI icons. Confidence: 0.8
- Dislikes tiny UI type and controls; wants fonts and components scaled up so the interface feels substantial. Confidence: 0.8
- Wants the best value in each metric column of benchmark/comparison tables visibly highlighted, not left for the reader to scan. Confidence: 0.6
- Wants decorative corner accents on panels/containers to be plain solid squares centered exactly on the border line, straddling it (half outside the container), not drawn inside the container or with cut/notched corners. Confidence: 0.6
- Prefers benchmark/comparison views to show only live-computed results; remove pre-saved/hardcoded "reference" score tables from pages rather than displaying them alongside a fresh run. Confidence: 0.55
- Judges UI harshly when it looks generic ("very sloppy, like cheap llm") and expects a deliberately designed, distinctive aesthetic. Confidence: 0.75
